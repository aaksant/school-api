## Requirements

- Addition of student/teacher/staff/exec entry
- Modification of student/teacher/staff/exec entry
- Deletion of student/teacher/staff/exec entry
- Get list of all student/teacher/staff/execs
- Authentication with login and logout
- Bulk modifications of student/teacher/staff/execs
- Class management: total count of a class with class teacher and list of all students in a class with class teacher
